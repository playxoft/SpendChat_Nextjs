# CLA signatures

This branch exists only to store contributor CLA signatures. It is written to
automatically by `.github/workflows/cla.yml` (CLA Assistant), which appends to
`signatures/cla.json` when a contributor signs on their first pull request.

Nothing here is source code, and nothing here should be edited by hand. The
agreement itself lives in [`CLA.md`](../../blob/master/CLA.md) on `master`.
